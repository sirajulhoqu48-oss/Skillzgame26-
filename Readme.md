# Skillzgame 🎮

Skillzgame is a multiplayer skill-based gaming web application.

## Features

- 🎮 Pro Match multiplayer gaming
- 🧩 Block Puzzle gameplay
- 🏆 Score and winner settlement
- 💰 Gaming balance and winning balance
- 💸 Deposit and withdrawal system
- 👥 Referral system with admin approval
- 👨‍💼 Admin Panel
- 🔐 Protected balance and transaction handling
- 📱 Android APK support
- ☁️ GitHub + Vercel deployment

## Pro Match

Players can join Pro Matches using the configured entry fee.

Each player can play their game independently, and submitted scores are securely stored for match settlement.

## Referral

Referral bonuses are not added automatically.

Eligible referral bonuses are first placed in **Pending Approval** status. An administrator can review and approve or reject the referral bonus from the Admin Panel.

## Deployment

The project can be deployed using Vercel with the GitHub repository.
